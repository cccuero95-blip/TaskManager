# TaskManager
Sistema de gestión de tareas

## Descripción
TaskManager es una aplicación web sencilla diseñada para
gestionar y organizar tareas personales.

## Objetivo
Facilitar la organización de actividades mediante una
interfaz sencilla e intuitiva.

## Funcionalidades
- Añadir tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Visualizar la lista de tareas.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Instalación y ejecución
1. Clonar el repositorio.
2. Abrir la carpeta TaskManager.
3. Ejecutar el archivo index.html en un navegador.
